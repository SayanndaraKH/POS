# 🍵 ប្រព័ន្ធគ្រប់គ្រងការលក់តែគុជ និងភេសជ្ជៈ (Boba & Beverage POS Web System)

ប្រព័ន្ធ POS លើគេហទំព័រត្រូវបានបង្កើតឡើងដោយប្រើប្រាស់ **Python (Flask) + SQLite + Modern Web UI** យ៉ាងស្រស់ស្អាត រហ័ស និងមានស្ថេរភាពខ្ពស់ គាំទ្រភាសាខ្មែរ រូបិយប័ណ្ណពីរ (USD / KHR) ការទូទាត់សាច់ប្រាក់ និង KHQR ព្រមទាំងការកាត់ស្តុកស្វ័យប្រវត្តិ។

---

## 🌟 មុខងារស្នូលទាំង ៤ សំខាន់ៗ (Core Modules)

### ១. មុខងារលក់ និងបញ្ជាទិញ (Point of Sale)
- **ចំណាត់ថ្នាក់ភេសជ្ជៈ**: តែគុជ (Milk Tea), កាហ្វេ (Coffee), តែផ្លែឈើ & ទឹកក្រឡុក (Smoothies), ភេសជ្ជៈពិសេស (Special Brews)។
- **ការកំណត់ជម្រើសបន្ថែម (Drink Customization)**:
  - ទំហំកែវ៖ កែវកណ្តាល (M) / កែវធំ (L)
  - កម្រិតជាតិស្ករ៖ 0%, 25%, 50%, 75%, 100%
  - កម្រិតទឹកកក៖ គ្មានទឹកកក (0%), ទឹកកកតិច (50%), ទឹកកកពេញ (100%), ភេសជ្ជៈក្តៅ (Hot)
  - ជម្រើស Toppings៖ គុជខ្មៅស្ករត្នោត, គុជសគ្រីស្តាល់, ពពុះឈីសក្រអូប, ពងមាន់ភូឌីង, ចាហួយដូង, គ្រាប់ជី
- **ការគិតប្រាក់ (Checkout & Payments)**:
  - **សាច់ប្រាក់ (Cash)**៖ ប៊ូតុងចុចលុយទទួលរហ័ស ($2, $5, $10, $20, $50, $100) គណនាប្រាក់អាប់ជា USD និង KHR ស្វ័យប្រវត្តិ។
  - **ស្កេន KHQR (Bakong)**៖ បង្កើត QR Code ភ្លាមៗសម្រាប់អតិថិជនស្កេនទូទាត់តាមកម្មវិធីធនាគារក្នុងស្រុក។
- **ការបោះពុម្ពវិក្កយបត្រ (Receipt Printing)**៖ ទម្រង់វិក្កយបត្រម៉ាស៊ីនព្រីនកម្ដៅ (Thermal Printer 80mm/58mm) បង្ហាញគ្រប់ព័ត៌មានលម្អិត។

---

### ២. គ្រប់គ្រងស្តុក និងផលិតផល (Inventory & Recipe BOM)
- **បញ្ជីមុខទំនិញ (Products CRUD)**៖ បន្ថែម កែប្រែ ឬផ្អាកលក់ភេសជ្ជៈ និងកំណត់តម្លៃ។
- **វត្ថុធាតុដើម (Raw Materials)**៖ គ្រប់គ្រងស្តុកកែវ, ទុយោ, គម្រប, គ្រាប់កាហ្វេ, ស្លឹកតែ, ម្សៅម៉ាត់ឆា, ទឹកដោះគោ, ស៊ីរ៉ូស្ករ, គ្រាប់គុជ។
- **កាត់ស្តុកស្វ័យប្រវត្តិ (Auto-Deduction BOM)**៖ រាល់ពេលមានការលក់ ប្រព័ន្ធកាត់វត្ថុធាតុដើម និង Topping តាមរូបមន្តដោយស្វ័យប្រវត្តិ។
- **ប្រព័ន្ធព្រមានជិតអស់ស្តុក (Low Stock Alert)**៖ បង្ហាញសញ្ញាព្រមានពណ៌ក្រហម/លឿងភ្លាមៗពេលស្តុកធ្លាក់ចុះក្រោមចំនួនកំណត់។
- **នាំចូលស្តុក (Stock-In)** និង **ប្រវត្តិកាត់ស្តុក (Stock Audit Trail)**។

---

### ៣. របាយការណ៍ និងការបង្ហាញទិន្នន័យ (Reporting & DataGridView)
- **ផ្ទាំងគ្រប់គ្រងស្ថិតិ (Visual Dashboard & KPIs)**៖ ចំណូលសរុបថ្ងៃនេះ, សប្តាហ៍, ខែ (ជា USD និង KHR), ចំនួនកែវលក់សរុប។
- **គំនូសតាង (Chart.js)**៖ Top 5 ភេសជ្ជៈលក់ដាច់ជាងគេ និងចំណែកចំណូលតាមប្រភេទភេសជ្ជៈ។
- **តារាងទិន្នន័យ (DataGridView)**៖
  - មុខងារបែងចែកទំព័រ (Pagination)
  - ការត្រងតាមកាលបរិច្ឆេទ (Date Range), អ្នកគិតលុយ (Cashier), វិធីទូទាត់ (Cash/KHQR), ស្ថានភាព (Completed/Void)
  - ស្វែងរកតាមលេខវិក្កយបត្ររហ័ស
- **ទាញយកទិន្នន័យ (Export)**៖ Export ជារបាយការណ៍ **Excel (.xlsx)** ឬ **CSV** ដោយចុចតែ ១ ឃ្លីក។
- **មុខងារ Void វិក្កយបត្រ**៖ អាច Void វិក្កយបត្រ និងត្រឡប់ស្តុកទំនិញចូលវិញដោយស្វ័យប្រវត្តិ។

---

### ៤. គ្រប់គ្រងគណនី វេនលក់ និងប្រព័ន្ធ (System Management)
- **ការបែងចែកសិទ្ធិ (Role-Based Access)**:
  - **អ្នកគ្រប់គ្រង (Admin)**៖ គ្រប់គ្រងបានគ្រប់មុខងារ (POS, ស្តុក, របាយការណ៍, ការកំណត់, អ្នកប្រើប្រាស់, Backup)
  - **អ្នកគិតលុយ (Cashier)**៖ ចូលប្រើបានតែផ្ទាំងលក់ POS និងគ្រប់គ្រងវេនលក់ផ្ទាល់ខ្លួន
- **គ្រប់គ្រងវេនលក់ និងថតលុយ (Shift Management)**៖ បើកវេន (Float Cash) និងបិទវេន (Drawer Reconciliation)។
- **បម្រុងទុកទិន្នន័យ (Data Backup & Restore)**៖ ទាញយក Database Backup (`.db`) និង Upload Restore ឡើងវិញដោយសុវត្ថិភាព។
- **ការកំណត់ទូទៅ (Store Settings)**៖ កែប្រែឈ្មោះហាង, ឡូហ្គោ, លេខទូរស័ព្ទ, អាសយដ្ឋាន, អត្រាប្តូរប្រាក់ (Exchange Rate)។

## 🚀 របៀបដំណើរការកម្មវិធី (How to Run)

### វិធីទី ១៖ ចុចពីរដងលើ File `run.bat` (សម្រាប់ Windows)
គ្រាន់តែចុចពីរដង (Double-Click) លើ file `run.bat` នោះប្រព័ន្ធនឹងដំណើរការភ្លាមៗ!

### វិធីទី ២៖ ដំណើរការតាម Terminal / PowerShell
```powershell
python app.py
```

បើកកម្មវិធីរុករក (Web Browser) របស់អ្នកទៅកាន់អាសយដ្ឋាន៖
👉 **http://127.0.0.1:5000**
